# Análise de Correspondência Simples(ANACOR) - Utilizados dados de compras
Analise de correspondência Simples(ANACOR) - Com dados de compras realizadas

<p>
  As análises de correspondência simples (ANACOR) ou múltipla (ACM) são técnicas de machine learning não supervisionadas que verificam a associação entre categorias de variáveis qualitativas, sem recorrer à ponderação arbitrária.
</p>
<p>
  ANACOR é um técnica de redução de dimensionalidade, partindo de um tabela de contingência, realizando transformações lineares que levam em consideração a correspondência entre e colunas da matriz de dados.
</p>

<p>
  Como resultado é obtido um mapa conceptual, uma apresentação visual das linhas e colunas da tabela de contingência  seus pontos representam as categorias nas respectivas dimensões.
</p>
 <p>
   Para realização de testes, foi utilizado dados de compras de supermercados cujo o objetivo foi a observação do tipo de pagamento em diferentes linhas de produtos(Product_line) ou segmentos foram utilizados dados de compras.
 </p>
<p>
  Os dados utilizados foram obtidos no kaggle link:
  https://www.kaggle.com/datasets/faresashraf1001/supermarket-sales
</p>
